GWENT GO
UI mockup — Material 3 concept for Android, Linux and Windows. Every frame below is a live HTML/CSS screen rendered at real device viewport sizes, using the card artwork and HUD sprites from the reference repository.
Android Android decks Desktop

Material 3 chrome

App bars, navigation rail, segmented buttons, chips, FABs and dialogs follow Material 3 on a gold-on-charcoal dark scheme.

Widget-built board

The battlefield is composed from containers, rows, badges and cards — no reference board image — so it can stay responsive and themable.

Reference artwork

Card art, shields, gems and ability icons are loaded from gwent-classic-enhanced/img; frames, banners and power badges are drawn in CSS.

Three difficulties

Easy / Normal / Hard appear in the home screen, the deck editor and as a chip on the opponent panel during a match.

Phone deck editor

A persistent summary bar keeps cards, units, specials, strength and validation visible while adding or removing cards, so the rules never hide behind a tab.

Notes
How to read these mockups
  • Screens are static concepts at real viewport sizes: 412 × 915 (Android) and 1280 × 800 (desktop). Nothing here is the Flutter app yet.
  • The match screen shows a live position: Biting Frost freezes both close-combat rows, Commander's Horn doubles the opponent's siege row, and the hand is mid-round 2.
  • Card artwork, shields, gems and ability icons are referenced from gwent-classic-enhanced/img — if that folder is missing, images will be blank.
  • Phone interaction concept: tap a hand card to lift it, then tap a highlighted row to place it; long-press opens the full card sheet. Desktop uses click + preview panel.
  • Deck editor concept: tap a card in the collection to add a copy, long-press for details; switch to the Deck tab to remove copies with steppers. The bottom summary bar stays visible in both tabs.
  • Strings are English and centralised, ready for ARB-based localization; difficulty and deck rules are surfaced in the UI.
